# pr1v

public chain. pr1v you.

The privacy layer for Solana: a live pump.fun trenches scanner with what is public about each dev, an opsec score for any wallet, funding traces, wallet linking, a browser fingerprint check, and sealed notes between wallets (NaCl box, written in Solana memos).

Reads only public chain data and Jupiter's token feed. Holds no keys. Optional env: `RPC_URL`, `PR1V_CA`, `PR1V_X`.
